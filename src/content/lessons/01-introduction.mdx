Lua is a small, fast, embeddable scripting language created in 1993 in Brazil. It wasn't designed to be a general-purpose language you build entire operating systems in — it was designed to be **dropped into other programs** so that program can be scripted and extended.

That single design goal explains almost everything about Lua: it's tiny (the reference implementation compiles to a few hundred KB), it has a small, consistent set of features, and it embeds into C (and by extension, C++, JavaScript, and more) with very little friction.

## Where you'll actually see Lua

- **Game development** — Lua is the scripting language behind *Roblox* (Luau, a Lua dialect), *World of Warcraft* addons, *Garry's Mod*, and engines like *LÖVE2D* and *Defold*.
- **Neovim** — modern Neovim configuration and plugins are written in Lua.
- **Embedded & IoT** — Lua's tiny footprint makes it popular for scripting on constrained hardware (e.g. NodeMCU on ESP8266/ESP32).
- **Adobe apps, Wireshark, Redis** — all let you script behavior with Lua.

## What makes Lua distinctive

- **One data structure to rule them all.** Lua has a single compound data structure — the **table** — which does the job of arrays, dictionaries, objects, and namespaces in most other languages.
- **1-based indexing.** Unlike C, JavaScript, or Python, Lua sequences start counting at `1`, not `0`.
- **Dynamically typed**, with a handful of core types: `nil`, `boolean`, `number`, `string`, `function`, `table`, and a couple of advanced ones you'll meet later (`userdata`, `thread`).
- **First-class functions and closures** baked in from the start.
- **No built-in class system** — instead, Lua gives you *metatables*, a small set of hooks powerful enough to build OOP, operator overloading, and more yourself.
